Built on Next.js 15 with the App Router: `app/` defines route segments per role (`candidate`, `admin`, `jobs`, `login`, `register`, `pipeline`, `talent`, `interviews/[roomName]`) and a server-side proxy at `app/api/interviews/token/route.ts` that forwards token requests to the backend's LiveKit endpoint. Shared layout is in `app/layout.tsx` which injects global styles and LiveKit CSS. Business logic is isolated under `lib/`: `auth.ts` persists JWT access/refresh tokens and session in `localStorage`; `api.ts` wraps `fetch` with Bearer auth, automatic refresh-on-401, and typed error classes; `use-api.ts` exposes React hooks over it. Feature components live in `components/<role>/` (e.g., `candidate`, `dashboard`, `interviews`, `jobs`, `pipeline`, `quiz`, `talent`) with a shared `components/ui/` primitive set (button, pill, table, etc.). Role-based entry gating is implemented via the `RequireAuth` client component in `components/auth/`. The voice/video interview flow uses `@livekit/components-react` and `livekit-client`, with the room wrapper in `components/interviews/livekit-interview-room.tsx` and a richer voice portal under `components/interviews/voice/`. Testing is configured with Vitest + jsdom under `tests/`.
