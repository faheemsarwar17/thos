Backend runs via `uvicorn app.main:app --host {HOST} --port {PORT}` (or `python -m uvicorn app.main:app`); startup triggers automatic column-level migrations discovered from `app/migrations/*.py`. Database selection is controlled by `DATABASE=sqlite|mysql` env var plus `DB_*` credentials. Production mode (`MODE=prod`) disables Swagger docs and enforces non-default secrets via `settings.validate_production_secrets()`. Frontend uses standard Next.js scripts (`npm run dev/build/start`) and depends on a running LiveKit server configured through `LIVEKIT_WS_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET`.
