Run with `uvicorn app.main:app --reload` (or via `hatch`); configure via `.env` with `THOS_*` prefixed variables (e.g. `THOS_DATABASE_URL`, `THOS_AI_API_KEY`, `THOS_LIVEKIT_*`); demo data seeding runs automatically on startup when `THOS_SEED_DEMO_DATA=true` and `THOS_ENVIRONMENT=development`; tests execute with `pytest` from the project root using the `tests/` directory and `-q` quiet mode.
